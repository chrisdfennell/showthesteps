# Security

Show The Steps is a static website: plain HTML and JavaScript pages with no server, no accounts and no logins. Everything a visitor saves (progress, settings, streaks) stays in their own browser. The only outside service is [GoatCounter](https://www.goatcounter.com), which counts page visits without cookies or personal data.

## Reporting a problem

If you find a security problem, for example a way to make a page run someone else's script from a crafted link, please report it **privately**:

- [Open a private security advisory](https://github.com/chrisdfennell/showthesteps/security/advisories/new) on GitHub.

Please don't open a public issue for it. You'll get a reply as soon as possible, and a fix will go out in a new release (see [Releases](https://github.com/chrisdfennell/showthesteps/releases)).

## Supported versions

Only the live site, the latest release, is supported. Every push to `main` is published as a new version.
