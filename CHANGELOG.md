# Changelog

Every push to `main` is versioned and released automatically (see [Versioning & releases](README.md#versioning-and-releases) in the README), so the full list of changes for each version is on the **[Releases page](https://github.com/chrisdfennell/showthesteps/releases)**.

How the version number moves:

| A commit whose… | Example | New version |
| --- | --- | --- |
| subject starts with **Add** | "Add the Graph Paper" | next minor: 1.4.2 → **1.5.0** |
| message contains **[major]** | a big change that breaks old links | next major: 1.4.2 → **2.0.0** |
| anything else | "Fix the labels on the grid" | next patch: 1.4.2 → **1.4.3** |

The version in use is shown in the home page footer and in the **?** menu on every page.
