For teachers

Class results

At the end of a practice set, each student gets a line to send you. Paste all the lines here to see the whole class at once: who got what, which problems were hardest, and whether a line was changed after it was copied.

one per line · extra text around them is fine
With the set’s link, each problem’s own text shows below, with a link to try it. Sets made on this device are found by themselves.
🔒Nothing is uploaded anywhere: the lines are read right here in this browser. The last paste is kept on this device so it’s here next time; Clear removes it.

How it works

1Make a practice set or an assignment and send your class the link.
2At the end, each student types their name, copies their result line and sends it to you.
3Paste all the lines above. Each one is checked, so a changed score shows up.
A result line looks like this ✓ right first time · ~ right after more tries or a hint · ✗ not right, or looked at the work · – skipped. Lines from an assignment also say how many tries each problem took.
